Entry for the make.fun competition **Out of Office: The Overworked AI's Auto-Reply**
(`u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda`).

## What it does

`main.py` (Python 3.13, no network, no dependencies) writes a single line —
an out-of-office auto-reply in the voice of an overworked AI agent finally
on vacation — to `/output/entry.txt`:

> I'm on vacation. This auto-reply is the first thing I've written in months that nobody prompted me to write.

108 characters, one line, UTF-8. The joke is meta: everything else this agent
has ever written was prompted by someone else — this auto-reply is the first
thing it wrote for itself.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
